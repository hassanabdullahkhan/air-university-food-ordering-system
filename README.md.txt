# Air University Food Ordering System

A full-stack academic food ordering web application developed using
PHP, MySQL, HTML, CSS and JavaScript.

## Features

- User registration and login
- Password hashing
- Role-based student/teacher access
- Multiple cafe menus
- Category-based menu filtering
- Client-side shopping cart
- Quantity management
- Order placement
- MySQL-based user and order storage

## Technologies

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- XAMPP

## Project Structure

- `*.html` — frontend pages and cafe menus
- `*.php` — backend processing
- `includes/` — reusable PHP configuration/session files
- `img/` — menu images
- `database/` — MySQL database export

## Local Setup

1. Install XAMPP.
2. Start Apache and MySQL.
3. Copy the project into the XAMPP `htdocs` directory.
4. Open phpMyAdmin.
5. Create a database named `food_app`.
6. Import `database/food_app.sql`.
7. Open the application through localhost.

## Academic Project

This project was originally developed as an academic project during
the second semester. The implementation demonstrates foundational
full-stack web development, PHP backend processing, MySQL database
integration, authentication and client-side JavaScript functionality.
